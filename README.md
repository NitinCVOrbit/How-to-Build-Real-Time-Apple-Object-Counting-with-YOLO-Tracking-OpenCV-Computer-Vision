# 🍎 Real-Time Apple Object Counting using YOLO & OpenCV

A real-time Computer Vision project that detects, tracks, and counts apples in a video using YOLO, OpenCV, and object tracking. The project uses ROI masking, persistent tracking IDs, center-point smoothing, and line-crossing detection to achieve accurate counting without duplicate detections.

## 🚀 Project Pipeline

Video → Frame Annotation → Dataset Augmentation → YOLO Training → Detection → Tracking → Line Crossing → Real-Time Counting

## 🛠️ Technologies Used

* Python
* YOLO (Ultralytics)
* OpenCV
* Roboflow
* Albumentations
* NumPy
* Google Colab
